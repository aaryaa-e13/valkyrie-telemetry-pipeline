## Inputs for the Phase 3 quality gates

Inputs only; the Phase 3 plan decides the rules.

| Input | Evidence (counts) | Candidate gate |
|---|---|---|
| Missing is not null | timeline events: 1791 absent fields, 0 explicit nulls; the simulator always sends every field, with null when unused | required-field checks must treat an absent key and null the same way |
| Empty strings in identifier-like fields | participant fields with empty strings: summonerName (500) | treat '' as missing for ids and names |
| Unknown event types | 19 real event types, 3 map to a simulator type; 44062 of 58540 events (75.3%) have none | an allowlist of event types; unknown types go to the dead-letter queue, counted, not dropped |
| Ties in event time | 14674 of 58540 events (25.1%) share the timestamp of the event before them | ordering and match_seq cannot come from time alone; keep the list position |
| Order and range of event times | out of order in listed order: 0; negative: 0; after GAME_END: 0; later than own frame: 0 | event_time within [game start, game end]; counts above say how strict this can be |
| Relative timestamps | event timestamps are ms since game start; absolute time needs info.gameStartTimestamp from the match file | a timeline without its match summary cannot get an event_time: hold or dead-letter it |
| Participant 0 on player events | participantId outside 1-10: 0_on_ITEM_PURCHASED (100), 0_on_SKILL_LEVEL_UP (27) | a purchase or skill event with participant 0 cannot be joined to a player: flag it (quarantine or keep with a null player), do not drop it |
| Non-champion actors | 7 of 2829 kills (0.2%) have killerId 0 | killer 0 is valid (not a player); a player join must allow it |
| Corrections in the stream | ITEM_UNDO: 567 vs 11599 purchases | a purchase is not final; downstream counts need undo handling |
| Natural keys collide | identical events beyond the first: 1981 (by type: WARD_PLACED: 1305, ITEM_DESTROYED: 410, ITEM_PURCHASED: 193, TURRET_PLATE_DESTROYED: 55, SKILL_LEVEL_UP: 18); (type, time, actor) collisions: 6114; with target: 2006 | event_id = match id + frame index + event index, not a content hash; only if the order is stable across fetches (see Open questions) |
| More than one patch | patches in the sample: 16.22 (30), 16.23 (20) | patch comes from each match (gameVersion cut to major.minor); the SCD2 patch dimension must expect several in one day |
